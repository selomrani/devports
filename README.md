# devports

A beautiful, cross-platform TUI for monitoring and managing local development ports. 

![Demo](demo.gif)

## Installation

**The easiest way (macOS & Linux):**
```bash
curl -sL https://selomrani.github.io/devports/install.sh | bash
```

**Using Go:**
```bash
go install github.com/selomrani/devports@latest
```

## Usage
Run `devports` to see a list of listening ports.
- Press `k` to kill a selected process
- Press `r` to refresh the list
- Press `q` or `Ctrl+C` to quit
